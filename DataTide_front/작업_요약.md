### 개요
현재 프로젝트의 핵심 목표는 **통계 차트**에 사용되는 라이브러리를 `Plotly.js`에서 `Chart.js`로 전환하는 것입니다. 사용자의 요청에 따라 **예측 차트**는 기존 `Plotly.js` 구현을 그대로 유지하여, 두 라이브러리가 공존하는 점진적인 마이그레이션을 진행합니다.

---

### 1. 완료된 작업 (Completed)

- **라이브러리 설치:**
  - `npm install chart.js react-chartjs-2` 명령어를 통해 Chart.js와 React용 연동 라이브러리(`react-chartjs-2`)를 프로젝트에 성공적으로 추가했습니다.
  - 기존 `react-plotly.js` 라이브러리는 '예측' 차트에서 계속 사용해야 하므로 **제거하지 않았습니다.**

---

### 2. 현재 진행 중인 작업 (In Progress)

- **데이터 구조 변경 (`src/utils/index.js`):**
  - **목표:** `generateMockChartData` 함수가 `analysisType` 값에 따라 두 가지 다른 데이터 구조를 반환하도록 수정하는 작업을 진행하고 있습니다.
    - `analysisType === '통계'`: **Chart.js**가 요구하는 `{ labels: [], datasets: [] }` 형식의 객체를 반환합니다.
    - `analysisType === '예측'`: **Plotly.js**가 요구하는 기존의 `traces` 배열 형식을 그대로 반환합니다.
  - **상황:** 이전에 몇 차례 코드 수정 시도가 있었으나, 파일 내용이 정확히 일치하지 않아 실패했습니다. 현재 파일의 최종본을 다시 읽어, 이 목표에 맞게 함수 전체를 깨끗한 코드로 교체하는 작업을 재시도하고 있습니다.

### 3. 앞으로 해야 할 작업 (To-Do)

- **차트 컴포넌트 교체 (`src/components/ChartComponent.jsx`):**
  - **가. 모듈 가져오기 (Import):**
    - 파일 상단에 `import { Bar } from 'react-chartjs-2';` 와 `import { Chart as ChartJS, ... } from 'chart.js';` 등 Chart.js에 필요한 모듈들을 추가합니다.
    - `ChartJS.register(...)`를 호출하여 필요한 기능(스케일, 툴팁, 범례 등)을 등록합니다.
  - **나. 조건부 렌더링 (Conditional Rendering):**
    - `return` 문 내부의 JSX를 수정하여 `analysisType` 값에 따라 다른 차트 컴포넌트를 렌더링합니다.
    - **'통계'의 경우:** Chart.js의 `<Bar>` 컴포넌트를 렌더링합니다.
    - **'예측'의 경우:** 기존 `Plotly.js`의 `<Plot>` 컴포넌트와 관련 로직을 **수정 없이 그대로 사용합니다.**
  - **다. Chart.js 옵션 생성:**
    - '통계' 차트에 사용될 `options` 객체를 생성합니다.
    - 이 객체에는 반응형 설정, 범례 스타일, 툴팁 동작 방식, 그리고 가장 중요한 **선/막대 그래프 혼합 및 중첩(stack)**을 위한 축(scales) 설정이 포함될 것입니다.

### 4. 주요 이슈 및 참고사항

- **수정 과정의 어려움:** `replace` 도구 사용 시, 교체 대상 문자열(`old_string`)이 파일의 현재 내용과 정확히 일치해야 합니다. 이전 작업에서 이 부분이 꼬이면서 작업이 지연되었습니다.
- **점진적 전환:** 사용자의 제안에 따라, 한 번에 모든 차트를 바꾸는 대신 '통계' 차트만 우선 전환하는 방식으로 전략을 수정했습니다. 이는 안정성을 높이고 예측 차트의 기존 기능을 보존하는 효과적인 방법입니다.
